Check your dependencies

Paste a requirements.txt or pyproject.toml to see how the packages your project needs are kept going, including the packages they need in turn.

Your file stays in your browser and is never uploaded. The page downloads the public data file for each package it finds, the same as opening that package's page.

What this check can't show
  • It maps the top {{ n_packages|comma }} PyPI packages only. Anything else shows as not covered, and we don't follow what it needs. Not covered doesn't mean healthy.
  • Dependencies come from each package's latest release, not the version you pinned. Optional extras aren't followed, and environment markers are ignored, so a package needed only on Windows still counts.
  • Activity describes commits on the default branch. Quiet can mean finished. Few active contributors is no criticism of anyone.
  • Lines it can't read, like -r other.txt, -e or a bare URL, are listed so you can check them yourself.
  • One list is limited to 100 named packages. The results are ordered by how far down your tree a package sits, then by name, never by health.
