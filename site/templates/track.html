Scoring rules

These were published before the first freeze (decision D15 in the decisions log).

  • A project counts as gone quiet if no human commit lands on its default branch in the 365 days after the freeze date.
  • Each file is graded once its 365 days are over, using log loss, against the simple rule frozen in the same file.
  • Projects whose history can't be read at grading time are left out and counted.
  • Frozen files are sorted by a hashed key so they aren't ranked lists.

Past-years test

This is a separate thing from the live record. See method and limits for the numbers.

What this can't show

Weekly forecasts overlap heavily, because the same projects appear each week, so 52 weeks of grades are not 52 independent tests. A year of results will cover only one year's conditions. Being graded as quiet doesn't mean a project was neglected: it may simply be finished.
